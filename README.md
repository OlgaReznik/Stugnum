# STUGNUM

Сайт stugnum.ee — статический сайт (HTML/CSS/JS), публикуется через GitHub Pages из ветки `main`.

- `assets/css/site.css` — все стили
- `assets/js/site.js` — header, footer, язык RU/ET, общее поведение
- `assets/js/pages/` — скрипты отдельных страниц
- `assets/data/projects.json` — список работ для портфолио
